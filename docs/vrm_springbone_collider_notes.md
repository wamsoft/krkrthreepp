# VRM SpringBone コライダー: 「髪が服に埋まる」現象の記録と対応

対象モデル: `data/model.vrm` (VRM 1.0, VRoid 製 "VRM1_Constraint_Twist_Sample")
記録日: 2026-08-01 / 実装: `src/vrm/VRM.cpp` (`VRMSpringBoneManager::collide`)

他の VRM 実装（three-vrm / UniVRM / 他ビューア）と挙動比較する際の参照用メモ。

## 現象

アニメーション中、**髪が胸の横あたり（胴体側面）に来たときに、服（ダボっとした T シャツ）に
不自然に埋まって見える**。前面や真下ではさほど目立たず、**側面**で顕著。

## 調査

### 1. コリジョン機構は VRM 側に存在し、実装済み
- `model.vrm` の髪 spring は `colliderGroups=[0..9]` を参照 = Spine / UpperChest / Neck / Head /
  L・R UpperArm / L・R LowerArm / L・R Hand の各コライダーに当たる想定。
- 実装 (`collide()`) は three-vrm 準拠（球・カプセルへの最近点距離 → `radius+hitRadius` まで tail を
  押し出し → ボーン長で再拘束）。コード上の欠陥は無い。

### 2. コリジョン ON/OFF の A/B 検証
- `collide()` を env で無効化して比較（検証後にガードは除去済み）。
- rest / swing / 前傾いずれの姿勢でも髪位置は **ほぼ同一** →
  「これらの姿勢では髪がそもそもコライダーの外側に垂れていて押し出しが発生していない」。

### 3. コライダー実寸（真横が手薄なのが原因）
`model.vrm` の胴体コライダー（ローカル offset[m] / radius）:

| collider | bone | 形状 | offset | tail | r |
|---|---|---|---|---|---|
| col0 | C_Spine | sphere | [0,0,0] | – | 0.114 |
| col1 | C_UpperChest | sphere | [0, 0.003, **-0.009**] | – | 0.095 |
| col2 | C_UpperChest | **capsule** | [**0.048**, 0.055, **+0.030**] | [**-0.048**, 0.055, +0.030] | 0.067 |
| col5/8 | L/R UpperArm | capsule | [0,-0.010,0] | [±0.143,-0.010,0] | 0.048 |

- 胸のカプセル col2 は **前面 (z=+0.030)** に左右へ張った横向き配置 → **真横 (z≈0) は覆わない**。
- 胸の球 col1 は r=0.095 で、胴体側面 (x≈±0.10) にわずかに届かない。
- UpperArm=x≈±0.109、UpperChest=原点付近。**胸中心の球/前面カプセルと腕カプセルの間、
  胴体の真横に ~3〜5cm のコライダー空白**がある。
- ダボっとしたシャツの側面メッシュは x≈±0.13〜0.15 まで膨らむため、その空白に垂れた髪が
  押し出されず、**シャツ側面の内側に埋まって見える**。

### 4. 根本原因（VRM の構造的性質）
- SpringBone コリジョンは **髪ボーンの中心線（tail 点）** に対してのみ効く。髪メッシュには太さが
  あり、服メッシュはコライダー（体を近似）より外側に膨らむ → **コリジョンが正しく効いても髪メッシュが
  服に食い込む余地が残る**。VRM 標準に **メッシュ同士（髪 vs 服）の当たり判定は無い**。
- 加えて本モデルは VRoid 自動生成コライダーが体にタイトで、特に**真横が手薄**。
- **three-vrm / UniVRM でも同じコライダーを使うため同様の埋まりが出るはず**（要確認ポイント）。

## 対応

**opt-in のコライダー半径一律スケール** を追加（既定 1.0 = 忠実）。

- 実装: `VRMSpringBoneManager::colliderScale`（`collide()` で `col.radius * colliderScale`）。
- API: `vrm.setColliderScale(1.4)` / `vrm.getColliderScale()`（ncbind 公開、`src/main.cpp`）。
- 効果: 実機で 1.0 vs 1.4 を比較 → **1.4 で胸横の髪が服から離れて自然**に。
  （＝コリジョンが正しく発火している裏付けにもなった。）
- コミット: 親 `90e5d81`。

注意: スケールを上げると前面・背面の髪も体から離れる。1.2〜1.4 が実用域。標準外の見た目調整で
あり、忠実性重視なら 1.0 のまま。

## 他実装と比較するときの観点
- 同モデルで **胸の真横に垂れた髪が服に埋まるか**（three-vrm/UniVRM でも出れば「モデル側の
  コライダー配置の癖」で確定）。
- その実装が **コライダー拡張 / hitRadius 調整 / 追加コライダー** の手段を持つか。
- **メッシュ衝突**（髪 vs 服）を持つ実装なら埋まらない（VRM 標準を超える拡張）。
- 根本解決は **モデル側でコライダーを服のシルエットまで配置し直す**こと（ランタイム非依存）。
